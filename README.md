# World Party

Prototipo navegable de una app para encontrar fiestas y eventos en cualquier ciudad: clubes, fiestas privadas y conciertos.

## Qué incluye
- **Inicio**: ciudad actual, destacados de la ciudad y ciudades con foto.
- **Ciudad**: filtros (Hoy, Este finde, Clubes, Fiestas privadas, Conciertos).
- **Evento**: detalle, line-up y entradas Early bird / General / VIP con contador y total.
- **Pago simulado** → entrada con QR y puntos ganados.
- **Mis entradas** y **Guardados**.
- **Perfil**: puntos, niveles y promos canjeables.

Todo es una sola página (`index.html`) sin dependencias. Los datos son de ejemplo y las fotos vienen de Unsplash.

## Verlo
Abre `index.html` en el navegador, o activa GitHub Pages (Settings → Pages → Branch `main`, carpeta `/`).
